# malaria-detection.sys


📊 Dataset

This project uses the Cell Images for Detecting Malaria dataset from Kaggle.

The dataset contains two categories:

- Parasitized (Malaria Infected)
- Uninfected (Healthy Cells)

The dataset is not included in this repository due to its size.

Download Dataset: https://www.kaggle.com/datasets/iarunava/cell-images-for-detecting-malaria
